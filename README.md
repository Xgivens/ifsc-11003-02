## Module 4

The CSS demo follows the instructor's starter structure with an external stylesheet in `css-demo/assets/css/style.css`. It includes type, class, ID, descendant, and pseudo-class selectors; border-box sizing; margins, padding, and borders; Flexbox navigation and card interiors; consistent typography and colors; and responsive Grid cards. Cards use one column below 700px, two from 700px, and three from 1000px. Navigation stacks at 540px and below. A skip link and visible focus styles support keyboard navigation.

The positioning lab uses floats for exercises 1 and 2 and absolute positioning for exercises 3 and 4. The fourth exercise uses a relative wrapper. The required approaches are included; optional extra-credit variants are not included.
